# Gallery images

Put your local gallery images in this folder, for example:

- `assets/gallery/photo-01.jpg`
- `assets/gallery/photo-02.jpg`

Then update the two matching `<a>` and `<img>` paths in `group/gallery.html` from `../assets/xiangran-cheng-introduction.webp` (or `../assets/materials-builders-mentor.webp`) to `../assets/gallery/photo-01.jpg` and `../assets/gallery/photo-02.jpg`.

For each image, also update `data-title`, `data-caption`, the heading, and `alt` text. Keep `data-gallery` on the link so the keyboard-accessible viewer includes the image. Use lowercase filenames without spaces; JPG, PNG, and WebP all work.
