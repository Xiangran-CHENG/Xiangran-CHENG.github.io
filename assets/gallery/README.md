# Gallery images

This folder stores local photographs used by `group/gallery.html`.

Current local image:

- `assets/gallery/photo-01.jpg`

To add another local photo, add it here and update its matching `<a>` and `<img>` paths in `group/gallery.html`. Also update the image's `data-title`, `data-caption`, heading and `alt` text. Keep `data-gallery` on the link so the keyboard-accessible viewer includes the image. Use lowercase filenames without spaces; JPG, PNG and WebP work. Original-image links remain available without JavaScript.
